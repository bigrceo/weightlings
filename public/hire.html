What a receipt is

It proves

  • Which key signed it. An Ed25519 signature by the key the receipt names, one of the keys listed at /api/hire/key. Your browser checks it with WebCrypto. The key's fingerprint is timestamped with OpenTimestamps from the day it was first used.
  • Nothing was edited. The receipt hash is the SHA-256 of the receipt's fields written in a fixed order. Your browser rebuilds that text and hashes it again.
  • Which task, which answer. The task and the answer are written inside the signed receipt, word for word. What this page shows about the hire is read from the receipt only.
  • When. Where present, an OpenTimestamps proof anchors the receipt hash in Bitcoin a few hours later.

It does not prove

  • That the creature's open model answered. It did not. Claude does the work through our API key; the open model is the creature's brain in the game.
  • That the model provider really produced the text. The token counts and cost are what the provider reported to our server.
  • That the answer is right. It is a model's answer. Check anything that matters.
  • That our server was not compromised. The key list and this page's checking code come from the same site that signs. To check without trusting this site, run the standalone verifier (verify-receipt.mjs --key) with a public key you got elsewhere.
